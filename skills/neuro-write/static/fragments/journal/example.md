# Journal profile: *Journal of Example Neuroimaging* (SYNTHETIC)

> **This is a fictional journal, invented purely to demonstrate the mechanism
> and to serve as the acceptance-test fixture.** It ships no real journal's
> content. Its rules are deliberately chosen to *differ* from common venues so
> that a test can confirm the drafted prose follows the declared profile rather
> than any hardcoded house style. To target a real journal, create a runtime
> venue profile via `neuro-venue`; do not edit this file.

The *Journal of Example Neuroimaging* (JEN) is a made-up venue for computational
neuroimaging. Use these declared rules when `journal = example`. Every rule
below is a *declared* value — the framework reads it as data; it is not inferred
from the journal's name.

## Structure and length

- **Abstract:** a single unstructured paragraph, **≤ 200 words** (note: not 250).
- **Keywords:** **4–6**, lowercase, comma-separated.
- **Section numbering:** flat integers — `1`, `2`, `3` — with **no** decimal
  sub-numbering (note: not `1.1.1`).
- **Section order:** Introduction, Methods, Experiments, Results, Discussion,
  Conclusion.

## Citations (deliberately NOT author–year)

- **Numbered / Vancouver style.** In-text citations are bracketed numbers in
  order of appearance: `[1]`, `[2]`, `[3–5]`. The reference list is numbered in
  citation order.
- Do **not** use `(Author, year)` for this venue — that is a different journal's
  convention. This contrast is the point of the fixture.

## Figures and tables

- **Refer to figures as "Figure N" spelled out** (e.g. "Figure 1", "Figure 2A")
  — note: not the abbreviated "Fig. N".
- Figure captions begin with a noun phrase describing the content.
- Tables are captioned **below** the table.
- The self-reference label for the authors' own method in comparison tables is
  **"Proposed"** (note: not "Ours").

## Front/back matter

- Author contributions as a free-text paragraph (no fixed taxonomy required).
- A Data Availability statement is required.
- Declare use of generative-AI tools in a short statement before the references.

## What this fixture proves

If a section drafted for `journal = example` comes back with **numbered
citations** and **"Figure N"** and a **≤200-word abstract**, that demonstrates
the writing core is driven by the declared profile — i.e. it is journal-agnostic
— rather than reproducing any single venue's baked-in style.
